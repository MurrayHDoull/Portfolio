Python: Embodied Carbon Optimisation

Personal Project · Python University of Sheffield Up to 5% carbon reduction

This project demonstrates the ability to solve real-world sustainability challenges through computational optimisation. I developed a Python tool that minimises embodied carbon in truss structures, achieving up to 5% carbon reductions through geometric optimisation.

The solution involved designing modular functions for structural analysis and implementing optimisation algorithms — array-based search and the bisection method — to identify low-carbon designs.

Skills developed

  • Systematic debugging and code documentation
  • Version control workflows
  • Translating engineering requirements into data-driven solutions

It showcases the capability to translate complex engineering requirements into efficient, data-driven solutions that deliver measurable environmental and economic value.
